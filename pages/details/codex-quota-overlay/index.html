工具简介

Codex Quota Overlay 是面向 Codex Desktop 的免费开源 Windows 辅助工具，在对话窗口附近显示剩余额度、重置倒计时、额度桶与使用节奏估算。通过本地 Codex App Server 读取额度数据，不读取对话内容，与 OpenAI 无官方关系。

免费额度

可用模型不适用（本地桌面辅助工具）
免费额度工具本身免费开源；显示的是本机 Codex 额度
使用周期随 Codex 账户额度周期
刷新周期随 Codex 重置倒计时

核心特性

  • 本地额度浮层
  • Quota Center 总览
  • 重置倒计时与使用节奏估算
  • MIT 开源、无订阅付费墙
