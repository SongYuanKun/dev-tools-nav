工具简介

Bitwarden 是开源密码管理器，支持多端同步、浏览器扩展与 CLI，可自建服务器，端到端加密，适合个人与团队。

核心特性

  • 跨平台与浏览器扩展
  • 端到端加密与自托管
  • CLI 与 API
