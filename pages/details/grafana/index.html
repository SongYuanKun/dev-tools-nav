工具简介

Grafana 是开源的指标可视化与告警平台，支持 Prometheus、InfluxDB、Loki、云厂商等数据源，可构建仪表盘与告警规则。

核心特性

  • 多数据源与丰富图表
  • 仪表盘与变量
  • 告警与 OnCall

快速上手

Docker 快速启动

docker run -d -p 3000:3000 grafana/grafana

默认登录

打开 http://localhost:3000，用户名 admin，密码 admin
