SSL Labs

Qualys 出品的 SSL/TLS 配置检测工具，对网站 HTTPS 配置进行全面评分和漏洞检测。

SSL扫描评分
访问官网 ↗

工具简介

SSL Labs 对任意域名的 TLS/SSL 配置进行深度检测，给出 A+ 至 F 的评分，并列出协议、套件、证书与已知漏洞，是加固 HTTPS 的必备工具。

核心特性

  • 协议与套件检测
  • 证书链与 OCSP 检查
  • 已知漏洞与配置建议

快速上手

在浏览器中检测

打开 https://www.ssllabs.com/ssltest/ 输入域名如 example.com 提交

API 方式提交扫描（需 API Key）

curl -X POST 'https://api.ssllabs.com/api/v3/analyze?host=example.com'
