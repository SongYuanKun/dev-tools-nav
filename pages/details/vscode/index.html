工具简介

VS Code 是微软推出的免费开源代码编辑器，基于 Electron 构建，支持 Windows/macOS/Linux。内置 Git、调试、智能补全，配合海量扩展可覆盖前端、后端、DevOps 全场景。

核心特性

  • 内置 Git 与终端
  • IntelliSense 智能补全与重构
  • 丰富的扩展市场（ESLint、Prettier、主题等）

快速上手

从命令行启动 VS Code

code .

安装扩展（示例：ESLint）

code --install-extension dbaeumer.vscode-eslint
