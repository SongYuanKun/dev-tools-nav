工具简介

Figma 是基于浏览器的协作设计工具，支持 UI、原型、设计系统与开发交付，支持实时协作与插件生态，免费版即可满足多数需求。

核心特性

  • 实时协作与评论
  • 组件与变体、设计系统
  • 开发模式与 CSS 导出

快速上手

安装桌面应用（可选）

从 https://www.figma.com/downloads/ 下载 Figma Desktop

在浏览器中打开文件

直接访问 figma.com 登录后 New design file 或打开分享链接
