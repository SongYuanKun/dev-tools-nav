工具简介

Sentry 提供错误追踪与性能监控，支持 JavaScript、Node、Python、Go 等多语言，可捕获异常、面包屑与 Release 关联，便于排查线上问题。

核心特性

  • 多语言 SDK 与 Source Map
  • Release 与用户反馈
  • 性能事务与告警

快速上手

前端（如 React）安装

npm install @sentry/react

初始化（在应用入口）

import * as Sentry from '@sentry/react';
Sentry.init({ dsn: 'https://xxx@xxx.ingest.sentry.io/xxx' });
