UptimeRobot

免费网站监控服务，每 5 分钟检测一次，支持 HTTP/HTTPS/Ping/Port 监控，宕机即时告警。

监控告警免费
访问官网 ↗

工具简介

UptimeRobot 提供 HTTP(s)、Ping、Port、关键词等监控，免费版每 5 分钟检查，支持邮件/短信/Webhook 告警与状态页。

核心特性

  • 多类型监控与 5 分钟间隔
  • 多种告警渠道与 Webhook
  • 公开状态页

快速上手

添加 HTTP 监控

在 Dashboard → Add New Monitor，选 HTTP(s)，填 URL 如 https://example.com

Webhook 告警（如 Slack）

Alerts → Add Alert Contact → Webhook，URL 填 Slack Incoming Webhook
