基于 WebContainers 的在线 IDE，支持 Node.js 全栈开发，速度极快，体验接近本地。

访问官网 ↗

工具简介

StackBlitz 基于 WebContainers 在浏览器中运行真实 Node 环境，支持 Next、Vue、Vite 等，无需安装即可全栈开发与分享。

核心特性

  • 浏览器内 Node 环境
  • 与 GitHub 同步与 PR
  • 可嵌入文档与教程
