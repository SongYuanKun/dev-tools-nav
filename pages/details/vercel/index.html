工具简介

Vercel 是面向前端与 Jamstack 的部署平台，与 GitHub/GitLab 集成后推送即部署，支持 Next、React、Vue 等，自带全球 CDN 与 Serverless 函数。

核心特性

  • Git 推送自动构建与部署
  • Edge 与 Serverless 函数
  • 预览环境与回滚

快速上手

全局安装并登录

npm i -g vercel && vercel login

在项目目录部署

vercel

生产环境部署

vercel --prod
