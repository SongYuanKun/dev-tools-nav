工具简介

PageSpeed Insights 基于 Lighthouse 对 URL 进行移动端与桌面端性能分析，给出 Core Web Vitals 与优化建议。

核心特性

  • Lighthouse 性能与最佳实践
  • Core Web Vitals
  • 实机与模拟数据
