工具简介

Cursor 是一款 AI 原生代码编辑器，基于 VS Code 构建并深度集成 Claude、GPT-4 等模型。支持自然语言生成代码、智能重构、错误修复、代码解释，被誉为开发者必备的 AI 编程神器。

免费额度

可用模型Claude/GPT（慢速模式）
免费额度2000 次代码补全/月
使用周期每月
刷新周期每月刷新

核心特性

  • Cmd+K 自然语言生成代码
  • Cmd+L 代码解释与问答
  • 智能重构与 Bug 修复
  • 多模型支持 (Claude/GPT)

快速上手

下载安装 Cursor

访问 cursor.sh 下载对应系统版本

导入 VS Code 配置

首次打开会提示导入 VS Code 插件和设置

使用 Cmd+K 生成代码

在编辑器中按 Cmd+K，输入描述让 AI 生成代码

实用技巧

Tab 键接受 AI 建议
可选中代码后让 AI 重构或解释
Composer 模式支持多文件协同编辑
